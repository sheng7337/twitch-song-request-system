# 🎵 點歌佇列

[English](queue.md) · **繁體中文** · [所有說明](../README_zh_TW.md)

觀眾點的歌，分成四個區塊：左邊是「**正在演唱**」和下方的「**待唱歌單**」，右邊是「**待審核**」和下方的「**已唱歌單**」。
直播畫面上的歌單顯示層顯示的是同一份清單。

## 第一次設定

- 歌曲清單來自你的 Google 試算表（[SETUP → Google 試算表設定](../../SETUP_zh_TW.md#google-試算表設定)）。
  每 5 分鐘自動重新載入，新增歌曲不用重新啟動。
- 每個兌換項目用試算表的哪些分頁，在「[🎟️ 兌換](rewards_zh_TW.md)」分頁設定。
- ⚙ →「**歌單分頁**」→「**練習分頁**」：這裡的歌不會被點或抽到，但雷虎練唱台照樣會準備，所以正在練的歌伴奏已經準備好。
  待審核的「**＋ 加入**」會加到這裡。

## 直播中

| 想要… | 這樣做 |
|---|---|
| 唱完一首 | 在「正在演唱」按「**✓ 唱完了**」：移到已唱歌單，並拉入下一首 |
| 調整順序 | 拖曳歌曲卡片，在區塊內或區塊之間 |
| 移除一首 | 按「**✕**」（退還觀眾的點數） |
| 自己加歌 | 手動點歌欄：輸入歌名，不需要頻道點數 |
| 重抽隨機點歌 | 按「**🎲**」從同樣的分頁再抽一首 |

每張卡片會顯示上次點歌的日期和點歌者、KEY（**+3**、**−2**…），以及在雷虎練唱台的狀態（**♫**，見「[🎤 雷虎練唱台](leihu_zh_TW.md)」）。

「**待審核**」放的是系統沒把握的點歌：

| 把握程度 | 結果 |
|---|---|
| 80% 以上 | 直接加入歌單 |
| 不到 80% | 進待審核，附上最接近的結果 |
| 完全沒比對到 | 進待審核，標題空白讓你填 |

改好歌名後按「**✓ 確認 → 加入歌單**」，或按「**✕**」退還。歌單上沒有的歌，「**🔍 搜尋**」會在歌詞網站和 YouTube 找
（雷虎練唱台需要開著），然後「**▶ 加入歌單並準備**」，或連同連結「**＋ 加入**」練習分頁。🎭 情境點歌也會在這裡等你送出
（「[🎭 情境點歌](../features/mood-requests_zh_TW.md)」）。

**點數**：按「✓ 唱完了」（或拖到已唱歌單）時，點歌會標成完成；從歌單或待審核移除時退還點數。「**✕ 全部清除**」不會處理兌換，
之後可以在 💬 聊天室用「待處理兌換」篩選找到。這只對點歌系統管理的兌換項目有效（「[🎟️ 兌換](rewards_zh_TW.md)」）。

## ⚙ 設定

- 「**歌單分頁**」：練習分頁（見上面）。
- 「**隨機點歌冷卻天數**」：這幾天內唱過的歌不會被抽到。
- 「**抽歌方式**」：「**加權**」優先抽比較久沒唱的歌（推薦），或「**完全隨機**」。已在歌單、正在演唱或已唱的歌，以及冷卻天數內的歌，一律不會抽到。
- 「**清空歌單**」。

## 遇到問題

- **某首歌一直進待審核**：試算表上的歌名和觀眾打的差太多。把另一種寫法加進試算表，或調寬 `server/config.js` 的 `MATCH_THRESHOLD`（0.2 較嚴格、0.6 較寬鬆）。
- **重新啟動後歌單還在**：歌單會保留 6 小時（`queue-state.json`）。
