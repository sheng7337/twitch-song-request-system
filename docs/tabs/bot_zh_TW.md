# 🤖 機器人

[English](bot.md) · **繁體中文** · [所有說明](../README_zh_TW.md)

自己的聊天室**指令**和**定時訊息**，取代 Nightbot。會用你的 Twitch 帳號發言，而且只有點歌系統開著時才會運作。
預設有 `!歌單`（歌單試算表連結）和 `!commands`。

## 第一次設定

1. 在這裡設定指令和定時訊息（見下面）。離開欄位時就會自動存好。
2. **記得把 Nightbot 裡相同的指令和定時訊息關掉**，不然聊天室會收到兩次。還沒搬過來的，就先留在 Nightbot。

## 指令

觀眾在訊息開頭打指令（或它的其他名稱），機器人就會回答。

- 「**指令**」和「**其他名稱**」（例如 `!songs !list`）。
- 「**誰可以用**」：所有人、訂閱者以上、VIP 以上，或只有管理員。
- 「**每** N **秒一次**」（所有人）和「**每位觀眾每** N **秒一次**」。不管怎麼設，機器人 30 秒內最多回答 10 次。
- **回覆內容**，最多 500 字，可以用這些變數：

| 變數 | 會變成 |
|---|---|
| `$(user)` | 打指令的觀眾名稱 |
| `$(touser)` | 指令後面的第一個詞（去掉 @）；沒有的話就是打指令的觀眾 |
| `$(query)` | 指令後面打的所有文字 |
| `$(count)` | 這個指令被用過幾次 |
| `$(channel)` | 你的頻道名稱 |
| `$(uptime)` | 這次直播開了多久 |
| `$(followage)` | 觀眾（或 `$(touser)`）追隨了多久 |
| `$(sheet)` | 你的歌單試算表連結 |
| `$(commands)` | 所有人都能用的指令 |
| `$(pick a\|b\|c)` | 隨機挑其中一個 |
| `$(random 1-100)` | 範圍內的隨機數字 |

- 「**▶ 試試看**」先看會說什麼，不會發出去。每個指令會顯示用過幾次。
- 點歌系統自己的指令（`!so`、`!tk`、`!endingtk`、`!watch`…）不能拿來用。

回覆不會執行程式或打開連結；以 `!` 開頭的回覆（例如來自 `$(query)`）也不會觸發指令。

## 定時訊息

機器人每隔幾分鐘自己發的訊息。

- 「**每** N **分鐘**」、「**聊天室至少** N **句**」（從上次發之後，聊天室安靜時就不會一直洗同一句），也可以設成「**只在直播中**」。
- 一次只發一則，間隔至少 2 分鐘。開台時重新計時。
- 「**📣 現在發**」立刻發出並重新計時。每個定時訊息會顯示下一次大約什麼時候發。

## 遇到問題

- **機器人沒有回答**：點歌系統沒開、指令是關著的、還在冷卻，或觀眾的身分不夠。分頁會顯示最後一則沒發出去的訊息和原因（例如 AutoMod 或慢速模式）。
- **聊天室收到兩次回答**：Nightbot 裡同樣的指令還開著。
