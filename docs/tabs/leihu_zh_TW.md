# 🎤 雷虎練唱台

[English](leihu.md) · **繁體中文** · [所有說明](../README_zh_TW.md)

[雷虎練唱台](https://github.com/LeihuTW/Leihu-singsing)（Leihu Singsing）是另一個免費程式，可以把 YouTube 影片做成附歌詞的伴奏，
並調成任何 KEY。只要它在同一台電腦上執行，點歌系統就會自動連上；沒有開著時，其他功能照常運作。這個分頁顯示雷虎練唱台自己的畫面。

## 第一次設定

1. 安裝雷虎練唱台。可以搭配 1.6.x–2.3.x。
2. **幫每首歌找 YouTube 連結**：雷虎練唱台用試算表 **YTLink** 欄位的連結找到你的歌。
   ⚙ →「**① 幫每首歌找 YouTube 連結**」→「**🔗 找 YouTube 連結**」可以幫你填好（雷虎練唱台需要開著）：
   1. 把歌曲清單試算表共用給頁面上的服務帳戶電子郵件，權限設為「**編輯者**」，再按「**檢查權限**」。只有儲存需要。
   2. 「**搜尋沒有連結的歌曲**」：每首約 8 秒，隨時可以停止、之後繼續。
   3. **檢視**：分成「正確」、「需要確認」、「找不到」。可以接受、略過、改選其他影片或貼上連結。
   4. **儲存**：只寫入**空白**的 YTLink 儲存格。沒有這個欄位的分頁會自動新增。
3. ⚙ →「**② 在雷虎練唱台準備這些歌**」：下載雷虎練唱台還沒有的有連結歌曲，做好伴奏和歌詞。每首幾分鐘、會用顯示卡，最好在沒直播時做。
4. 選用：⚙ →「**和點歌系統一起啟動雷虎練唱台**」。按「**▶ 啟動雷虎練唱台**」時它不會開自己的視窗，只顯示在這個分頁。

## 直播中

- 歌單上的每首歌有 **♫ 標籤**：已就緒／沒有歌詞／準備中／失敗／準備／連結。
  「**♫ 準備**」依 YTLink 匯入；「**♫ 連結**」選雷虎練唱台裡已經有的歌。
- 「正在演唱」的「**🎤 練唱**」會在雷虎練唱台以試算表的 KEY 開啟這首歌。
- 忘了切唱歌模式時，最上面會出現提醒和「**切到 🎤 唱歌**」（「[🎛 模式](modes_zh_TW.md)」）。
- 歌詞：雷虎練唱台把試算表歌曲的歌詞留白，或標示有更合適的線上歌詞時，會套用線上歌詞，但只套用完全吻合的（歌名、歌手、長度都相同）。
  你自己選的歌詞永遠不會被取代。

### 📱 提詞機：在平板上看歌詞和聊天室

給防噴罩擋住螢幕時用。平板或手機（和這台電腦連同一個 Wi-Fi）開 ⚙ →「**📱 在平板上看歌詞和聊天室**」裡的網址
（`http://<這台電腦>:3000/prompter`）。會顯示雷虎練唱台正在播的歌詞（跟著唱的位置上色）、歌曲進度和聊天室：直放時聊天室在下面，
橫放時在右邊。歌詞和聊天室的字可以各自放大縮小，也可以隱藏聊天室。只是顯示，不會改到雷虎練唱台或直播。
iPad 上按「分享 →**加入主畫面**」，之後會全螢幕開啟。

## ⚙ 設定

- 「**自動準備歌單上的歌曲**」：歌曲加入歌單時就匯入，並預先產生它的 KEY。直播時會使用顯示卡（GPU）。
- 「**🔊 開啟直播專用視窗**」：見下面「OBS 裡的雷虎練唱台聲音」。
- 上面的兩個步驟、提詞機的網址，以及雷虎練唱台自己的設定。

## OBS 裡的雷虎練唱台聲音

在這個分頁裡，雷虎練唱台的聲音由瀏覽器播放。`start_zh.bat` 會用另外獨立執行的 Chrome（或 Edge）開啟控制台，讓 OBS 能單獨擷取：
新增「**應用程式音訊擷取**」，選擇視窗「**點歌控制台 Song Queue (OBS)**」，並把視窗比對方式設為「**視窗標題必須相符**」。

**音樂和人聲不同步**（約 200 ms，一下快一下慢）：應用程式音訊擷取沒有裝置時脈。改從輸出裝置擷取，它跟著裝置的時脈，和麥克風一樣：
- 「**音訊輸出擷取**」你聽的那個輸出裝置（最簡單，但那個裝置上的其他聲音也會進直播），或
- 讓雷虎練唱台用自己的輸出裝置（雷虎練唱台 ⚙ → 音樂輸出裝置）再擷取它：錄音介面有**硬體虛擬輸出**的話用它
  （例如 SSL 2 MKII 的「Output 3/4 (Virtual)」），或用虛擬音訊線，例如 **VB-Audio Virtual Cable**（擷取設為「監聽並輸出」，再設定一次同步偏移）。

**雷虎練唱台的全域快捷鍵**（Ctrl+Alt+Space 等，也可以給 Stream Deck 用）屬於雷虎練唱台自己的視窗。用「**▶ 啟動雷虎練唱台**」啟動時沒有快捷鍵；
兩個都開著時，快捷鍵控制的是雷虎練唱台的視窗，不是這個分頁。

## 遇到問題

- **♫ YouTube 拒絕下載**：YouTube 暫時拒絕你的網路連線下載。見「[SETUP → YouTube 拒絕下載](../../SETUP_zh_TW.md#youtube-拒絕下載)」。
- **YouTube 下載是關著的**（雷虎練唱台 2.3.1 起預設關閉）：點歌系統會說明怎麼開啟。開啟前不會匯入，歌也不會被標成失敗。
- **分頁是空的**：雷虎練唱台的畫面只能在執行它的電腦上顯示。
