# 👕 換裝

[English](outfits.md) · **繁體中文** · [所有說明](../README_zh_TW.md)

觀眾兌換獎勵，由你選要換哪套衣服：veadotube mini（2.1 以上）的角色狀態。

## 第一次設定

1. 在 veadotube mini →「**program settings**」開啟「**WebSocket server**」。
2. 打開「**👕 換裝**」：會列出你的 veadotube 視窗和每個狀態的圖片，點一下就換上。
3. 在平常穿的那套按「**☆**」：它就是預設服裝，它所在的視窗就是兌換會換裝的視窗。同一個角色開在兩個視窗時，
   每次打開 veadotube 之後，在正確的視窗按一次 ☆。
4. 在「[🎟️ 兌換](rewards_zh_TW.md)」分頁把會換裝的項目設為「**👕 換裝**」。
5. 回到這裡，在「**兌換**」設定「**換回預設服裝的時間**」N 分鐘後（0 = 一直穿到下一次兌換）。

## 直播中

有人兌換時，任何分頁都會跳出列出服裝的卡片，點要換上的那套。點歌系統管理的項目會自動標成完成，也可以按「**↩ 退還**」；
其他項目會留在 Twitch 自己的佇列。

## 遇到問題

- **沒有列出視窗**：veadotube 的 WebSocket server 沒開，或 veadotube 沒有在執行。
- **換到錯的視窗**：在正確的視窗再按一次 ☆（同一個角色開兩個時，每次打開 veadotube 之後都要按一次）。
