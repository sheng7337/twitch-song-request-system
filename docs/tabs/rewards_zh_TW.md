# 🎟️ 兌換

[English](rewards.md) · **繁體中文** · [所有說明](../README_zh_TW.md)

頻道上每個頻道點數兌換項目各一列：它的用途、有沒有特效，以及點歌系統能不能把它的兌換標成完成或退還。

## 每個兌換項目

- 「**用途**」—— 主要用途：
  - 「**🎤 點歌**」：觀眾輸入歌名。一定要有一個：要換的話，把另一個項目設為 🎤。它一定要讓觀眾輸入文字：沒有的話那一列會提醒你；
    請到 Twitch 為它開啟「**要求觀眾輸入文字**」。
  - 「**🎲 隨機點歌**」：抽一首歌。
  - 🎤 和 🎲 還可以勾選要用哪些歌單分頁（都不勾 = 練習分頁以外全部）。
  - 「**👕 換裝**」：由你選服裝（「[👕 換裝](outfits_zh_TW.md)」）。
  - 「**🎭 情境點歌**」：Claude 依觀眾的心情選一首歌（「[🎭 情境點歌](../features/mood-requests_zh_TW.md)」）。一樣要讓觀眾輸入文字；
    Anthropic API 金鑰和心情標記在清單下方設定。
  - 或是無。
- 「**🎟️ 特效**」—— 音效或圖片，可以單獨使用，也可以加在主要用途上（例如換裝時加一個音效）。「**→ 特效設定**」打開「[🔔 通知](alerts_zh_TW.md#兌換特效)」裡的設定。
- **完成／退還** —— 由主要用途決定（點歌在唱完或移除時、換裝在你選好服裝時、情境點歌在你拒絕選好的歌時）；只有特效的項目，就交給特效。

## ＋ 新增兌換項目

直接在這裡建立兌換項目：名稱、點數、用途、說明，以及要不要讓觀眾輸入文字。由點歌系統建立，所以一建立就由它管理（可以完成和退還）。

## 把在 Twitch 建立的項目交給點歌系統管理

Twitch 只讓程式完成或退還它自己建立的項目。在 Twitch 建立的項目可以交接過來：系統會建立一個設定相同的隱藏複本。到 Twitch 刪除原本的項目
（先清空它的佇列），複本就會接手它的名稱和位置，連同用途和特效。只有自訂圖示要重新上傳。

點歌、隨機點歌或換裝的項目如果沒辦法退還點數（還沒交給點歌系統管理，或在 Twitch 開了「**略過獎勵請求佇列**」），會顯示 ⚠ 和解決方法。

## 遇到問題

- **沒有退還點數**：這個項目不是點歌系統管理的（見上面），或它在 Twitch 開了「略過獎勵請求佇列」（兌換會立刻完成，沒有可以退還的）。
- **🎭 或 🎤 的項目提醒要輸入文字**：到 Twitch 為它開啟「**要求觀眾輸入文字**」。
