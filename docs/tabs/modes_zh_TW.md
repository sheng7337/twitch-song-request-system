# 🎛 模式

[English](modes.md) · **繁體中文** · [所有說明](../README_zh_TW.md)

控制台最上方的按鈕，例如「**🎤 唱歌**」、「**💬 聊天**」、「**☕ 休息**」。按一下就會把 Streamlabs Desktop 或 OBS Studio 恢復成存下的樣子
（場景、顯示什麼、聲音），並做點歌系統這邊的事：發聊天室訊息、暫停 Clip、暫停兌換特效、開啟某個分頁。

## 第一次設定

**連線**（🎛 模式 → 直播軟體）。只在這台電腦上連線；Token 或密碼存在 `.env`。
- **Streamlabs Desktop**：設定 → Remote Control → 點 QR code →「**Show details**」，把 Token 複製到控制台。千萬不要在直播畫面上顯示那個 QR code。
- **OBS Studio 30 以上**：工具 → WebSocket 伺服器設定 → 勾選「**啟用 WebSocket 伺服器**」。有開驗證的話，從「**顯示連線資訊**」複製密碼。

**建立模式**：先在直播軟體手動擺成想要的樣子，再按「**＋ 用目前畫面新增模式**」（或 🎤／💬／☕ 的範本）。模式會存下：
- 場景；
- 場景裡（以及裡面的場景和群組）顯示哪些項目；
- 這些場景聽得到的音訊的靜音和音量：場景裡的來源，加上不在任何場景裡的裝置，例如桌面音訊和麥克風（Streamlabs 用 %、OBS 用 dB）。
  其他場景的音訊不會被動到；要一起設定的話用「**＋**」加入。

## 直播中

按模式的按鈕。有 Clip 在等時，最上面一列會顯示「**⏸ N 個等待中**」：按一下看清單，「**▶ 現在播放**」立刻播，「**✕ 不播**」略過
（`!tk` 的名單會放回去）。

**🎤 忘了切唱歌模式？** 雷虎練唱台在不是唱歌的模式下播放歌曲時（例如聊天模式的 BGM 還開著），最上面會出現提醒和「**切到 🎤 唱歌**」。
按了才會切換，直播畫面不會自己改變。需要雷虎練唱台 1.4.3 以上。

## 修改模式

「**✎ 編輯**」可以看到內容。
- 「**👁／🚫**」顯示或隱藏項目；「**🔊／🔇**」有聲音或靜音（變暗＝關），也可以改音量。「**✕**」把項目移出模式，模式就不會動它。
- 「**📍 位置**」（在 👁 旁邊；變暗＝關）：項目也會放回存下的位置（位置、大小、旋轉、裁切）。畫布大小在存下之後變了的話，模式不會移動任何東西。
- 「**📥 把 … 目前的狀態存進這個模式**」從直播軟體重新存一次全部。
- **雙重輸出（Streamlabs Dual Output）**：每個項目在每個畫面各列一次，各自有 👁 和 📍。
- 點歌系統這邊：
  - 切換到這個模式時在聊天室發的**訊息**；
  - 「**⏸ 這個模式時暫停播放 Clip**」：`!so`、`!watch`、`!tk`、`!endingtk` 會先排著（最多 10 個）到下一個模式再播；正在播的會播完；
  - 「**🎟️ 這個模式時暫停兌換特效**」（「[🔔 通知](alerts_zh_TW.md#兌換特效)」）；
  - 「**🎤 唱歌用**」：上面的提醒把這個模式算成唱歌（原本會暫停 Clip 的模式預設勾選）；
  - 要開啟的控制台分頁。

## 遇到問題

- **改名**的項目、場景、音訊還是找得到；刪掉又用同樣名字建立的，會用名字找到。
- **不見的**會跳過，其他照樣套用。通知會列出跳過了什麼，模式會標上 ⚠，可以「**選一個替代…**」或「**✕**」。
- **之後新增**的項目不會被動到：編輯畫面列在「不在這個模式裡」，按「**＋**」加入。
- **工作室模式**：OBS 會直接切換節目畫面；Streamlabs 可能只會切換預覽，請再按轉場。
