# 🔔 通知和 🎟️ 兌換特效

[English](alerts.md) · **繁體中文** · [所有說明](../README_zh_TW.md)

**通知**：在直播畫面上顯示追隨、訂閱、贈訂、小奇點和揪團，取代 Streamlabs 的 Alert Box。一次一則，使用疊加層的主題和語言；
一次送出多份訂閱只顯示一則。
**兌換特效**：頻道點數兌換時播放音效、圖片／GIF／影片，或兩者都有，取代 TriggerFyre。

## 第一次設定：通知

1. 新增「**瀏覽器**」來源，兩種版面選一個（分頁上有列出，可以按「**複製**」）：
   - `http://localhost:3000/overlay/alerts.html?layout=vertical`：圖片在上，寬度 `800`、高度 `600`
   - `http://localhost:3000/overlay/alerts.html?layout=horizontal`：圖片在左，寬度 `1600`、高度 `300`
2. 縮小到 50% 並放好位置（以 2 倍解析度渲染）。沒有通知時是透明的。
3. **聲音**：在來源的內容勾選「**透過 OBS 控制音訊**」，再到混音器（⚙ →「**進階音訊屬性**」）把音訊監聽設成「**監聽並輸出**」，自己也聽得到。
   這樣聲音會跟著這個來源的音量和靜音，所以把來源靜音的模式（🎤 唱歌）會安靜地顯示通知。
4. 自己的圖片、GIF、影片和音效：把檔案放進 `alert-media` 資料夾，按「**↻ 重新讀取資料夾**」，再為每一種選檔案。
   沒有自己的檔案時，每一種會顯示內建圖示、播放內建提示音。

從 Streamlabs 換過來：先兩個一起開一場（把 Alert Box 靜音），再刪掉 Alert Box。

## 每一種通知

- 開／關、最低數量（小奇點、揪團人數…）、顯示多久、音量，以及達到某個數量時的「**大型版本**」（例如 50 人以上的揪團）：更大、更久，可以有自己的圖片和音效。
- 「**🔊 預設音效**」（在各種通知上面）是設成「（預設：…）」的每一種播的音效，選一次就全部改好。
- 音效檔不用自己調音量：播放時每個檔案都會調成一樣大聲（−16 LUFS），檔案本身不會被改。
- 「**▶ 測試**」只在直播畫面上顯示一則假的通知（不會發到 Twitch）。「**↻ 重播**」再顯示一次最近的通知。

## 兌換特效

1. 新增「**瀏覽器**」來源：`http://localhost:3000/overlay/reward-effects.html`，寬度 `1920`、高度 `1080`，蓋住整個場景（放在最上層）。
   和通知一樣勾選「**透過 OBS 控制音訊**」、設成「**監聽並輸出**」。
2. 在「[🎟️ 兌換](rewards_zh_TW.md)」分頁勾選那個項目的「**🎟️ 特效**」。回到這裡設定：
   - **音效**（放好幾個 = 每次隨機播一個）；
   - **圖片**：`alert-media` 裡的檔案，或「**🎟️ 兌換項目的圖示**」（Twitch 上那個項目的圖示，112 × 112，沒有自己的圖示就用 Twitch 預設的）。
     新加上特效的項目會先用它，大小 10%：圖示很小，放大會糊。在 Twitch 換了圖示，特效也會跟著換；
   - 位置和大小、顯示多久（或跟音效一樣長），以及「**顯示兌換的人**」。
3. 「**▶ 測試**」只在直播畫面上播放。
4. 「**同時兩個**」：依序播放、一起播放（最多 3 個），或跳過新的。

**點數**：特效播完後，兌換會標成完成。沒有播的（「**🔇 關閉**」、被跳過、排隊超過 20 個、「**🗑 清除排隊**」）會退還點數。
同時是點歌、隨機點歌、換裝或情境點歌的項目，完成和退還交給那個功能，特效只負責播放。只有點歌系統管理的項目能標成完成或退還；
其他項目一樣會播放（「[🎟️ 兌換](rewards_zh_TW.md)」）。

**排隊**：「**⏸ 暫停**」，或勾選「**🎟️ 這個模式時暫停兌換特效**」的模式（例如 🎤 唱歌），會讓兌換先排隊，結束後再播。OBS 裡沒有開啟兌換特效的來源時也會先排隊，
分頁上會提醒你。重新啟動時排隊中的不會保留：它們會留在 Twitch 自己的兌換佇列。

從 TriggerFyre 換過來：把音效和圖片存到 `alert-media`，在這裡設定好，再到 TriggerFyre 把每一個關掉，否則會播兩次。

## 遇到問題

- **直播上沒有聲音**：沒有勾選「透過 OBS 控制音訊」，或目前的模式把來源靜音了。
- **特效一直沒播**：OBS 裡沒有開啟兌換特效的來源、特效暫停中，或那個項目的特效是關著的。
