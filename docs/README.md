**New here?** Start with the [Starter Guide](STARTER_GUIDE.md): installing, the setup wizard and your first stream.
Installing, configuration and fixing problems: [SETUP.md](../SETUP.md).

In the dashboard, **❓** (at the right of the tab bar) opens the page of the tab you're on.

## The dashboard's tabs

| Tab | What it's for |
|---|---|
| [🎵 Song Queue](tabs/queue.md) | The requests: Now Playing, Up Next, Pending Review, Played; random picks; the practice tab |
| [🎤 Leihu Singsing](tabs/leihu.md) | Backing tracks and lyrics; finding YouTube links; 📱 the prompter on a tablet |
| [💬 Chat](tabs/chat.md) | Live chat, what to thank, posting, moderating, Shoutout, Raid, Pin |
| [🎛 Modes](tabs/modes.md) | One click sets Streamlabs / OBS and this app for singing, talking or a break |
| [👕 Outfits](tabs/outfits.md) | Redemptions that change your veadotube mini outfit |
| [🔔 Alerts](tabs/alerts.md) | Follow / sub / cheer / raid alerts, and 🎟️ reward effects |
| [🎟️ Rewards](tabs/rewards.md) | What each channel-point reward is for; new rewards; handing rewards over |
| [🤖 Bot](tabs/bot.md) | Your own chat commands and timers, instead of Nightbot |
