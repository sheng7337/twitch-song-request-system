# 🖼 疊加層和 🎨 外觀

[English](overlays.md) · **繁體中文** · [所有說明](../README_zh_TW.md)

點歌系統在直播畫面上顯示的每樣東西，都是 OBS 或 Streamlabs 裡的一個「**瀏覽器**」來源。每個來源的網址和大小都在控制台最上面、
EN／中文旁邊的「**🎨 外觀與疊加層**」，可以按「**複製**」。

| 來源 | 網址 | 大小 | 說明 |
|---|---|---|---|
| 歌單顯示層 | `/overlay/index.html` | 960 × 1470，縮小到 50% | 見下面 |
| Clip Player | `/clip-player/index.html` | 1920 × 1080，全螢幕、最上層 | 見下面 |
| 直播畫面上的聊天室 | `/overlay/chat.html?style=…` | 例如 960 × 1080，縮小到 50% | 見下面 |
| 通知 | `/overlay/alerts.html?layout=…` | 800 × 600 或 1600 × 300，縮小到 50% | 「[🔔 通知](../tabs/alerts_zh_TW.md)」 |
| 兌換特效 | `/overlay/reward-effects.html` | 1920 × 1080，全螢幕、最上層 | 「[🔔 通知](../tabs/alerts_zh_TW.md#兌換特效)」 |
| 休息中／準備中卡片 | `/overlay/break.html`（`?card=opening`） | 960 × 260，縮小到 50% | 見下面 |
| 提詞機（平板，不是 OBS） | `/prompter` | | 「[🎤 雷虎練唱台](../tabs/leihu_zh_TW.md#-提詞機在平板上看歌詞和聊天室)」 |

每個網址前面都是 `http://localhost:3000`。沒有東西要顯示時都是透明的。

## 歌單顯示層

1. 新增「**瀏覽器**」來源：`http://localhost:3000/overlay/index.html`，寬度 `960`、高度 `1470`。
2. 「**自訂 CSS**」：
   ```css
   body { background-color: rgba(0, 0, 0, 0) !important; margin: 0px auto; overflow: hidden; }
   ```
3. 取消勾選「**來源不可見時關閉**」。
4. 在場景中縮小到 `480 × 735`（50%）：以 2 倍解析度渲染，文字比較清晰。

## Clip Player

新增「**瀏覽器**」來源：`http://localhost:3000/clip-player/index.html`，寬度 `1920`、高度 `1080`，放在場景最上層、蓋住整個畫面。
只有 `!so`、`!watch`、`!tk` 和 `!endingtk` 時才會顯示內容（「[Clip 和感謝名單](clips-and-rolls_zh_TW.md)」）。

## 直播畫面上的聊天室

在直播畫面上顯示 Twitch 聊天室，取代 OneComme：最近的訊息，最新的在最下面，有徽章、表情符號和小奇點，還有頻道點數兌換和訂閱／贈訂／揪團／追隨。

1. 新增「**瀏覽器**」來源，選一種樣式（💬 聊天室 → ⚙ →「**直播畫面上的聊天室**」有列出，可以按「**複製**」）：
   - `…/overlay/chat.html?style=panel`：跟歌單一樣的面板
   - `…/overlay/chat.html?style=bubble`：對話泡泡
   - `…/overlay/chat.html?style=list`：簡單列表（文字有外框），適合疊在遊戲或影片上
   - `…/overlay/chat.html?style=row`：橫向一排，例如放在畫面最上方：最新的在右邊（`3840 × 200`）
2. 大小不限，例如 `960 × 1080`，自訂 CSS 和歌單顯示層一樣，縮小到 50%。
3. 💬 聊天室 → ⚙ →「**直播畫面上的聊天室**」：顯示幾則、文字大小，以及要不要顯示兌換、訂閱／揪團／追隨、`!指令` 和機器人。變更會立刻生效。

管理員刪除的訊息，以及被禁言或封鎖的觀眾的訊息，會立刻從直播畫面消失。從 OneComme 換過來：先兩個一起開一場，再刪掉 OneComme 的來源；
有顯示或隱藏它的模式會標上 ⚠：用「**選一個替代…**」換成新的聊天室。

## ☕ 休息中／準備中卡片

跟歌單一樣風格的卡片，搭配模式（☕）顯示。新增「**瀏覽器**」來源，寬度 `960`、高度 `260`，縮小到 50%：
- `http://localhost:3000/overlay/break.html`：「**休息中**」；加上 `?card=opening`：「**準備中**」（綠色）。
- `?min=10` 倒數 10 分鐘，`?at=20:00` 倒數到 20:00（之後顯示「馬上回來」／「馬上開始」）。都沒有的話，休息卡會往上計時，準備中卡會顯示時間。
- 頁面載入時開始計時：勾選「**場景變為作用中時重新整理瀏覽器**」（或「**來源不可見時關閉**」），每次休息才會重新開始。
- 文字大小在「🎨 外觀與疊加層」。

## 🎨 外觀與疊加層

不屬於單一分頁的設定都在這裡：
- **主題**：「**霓虹**」（原本的樣子）、「**日光**」、「**高對比**」、「**海洋**」、「**奶油咖啡**」，控制台和疊加層分開選。讓某一個疊加層用不同的主題：
  在它的網址加上 `?theme=daylight`（`neon`、`daylight`、`contrast`、`ocean`、`coffee`）。
- **文字大小**：控制台的（85–140%，每個開啟控制台的瀏覽器和手機都一樣）、歌單的和休息卡的。疊加層會立刻改變，在 OBS 裡的大小不變
  （文字越大，同樣的空間顯示的歌越少）。聊天室的文字大小在 💬 聊天室 → ⚙。
- **疊加層**：面板不透明度、亮度和「**疊加層語言**」（English 或繁體中文）。
- 每個疊加層的網址和大小、版本，以及「**📂 這次執行的紀錄**」。

「**EN／中文**」同時切換控制台、YouTube 連結頁和安裝精靈的語言；疊加層則依「**疊加層語言**」。

## 遇到問題

- **疊加層一片空白**：點歌系統沒開，或網址不對（從「🎨 外觀與疊加層」複製）。
- **文字糊糊的**：來源沒有用 2 倍大小（例如 960 × 1470）再縮小到 50%。
- **通知或兌換特效沒有聲音**：在來源勾選「**透過 OBS 控制音訊**」，並確認目前的模式沒有把它靜音。
