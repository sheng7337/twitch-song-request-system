# 🎭 情境點歌

[English](mood-requests.md) · **繁體中文** · [所有說明](../README_zh_TW.md)

觀眾兌換設成 🎭 的項目，寫下現在的心情（例如「今天好寂寞」）。Claude（Anthropic 的 AI，Claude Opus 5.5）會從你的歌單挑一首歌，
並寫一句要發到聊天室的話（中文和英文各一句）。**一定要你看過才會送出。**

## 第一次設定

1. 在「[🎟️ 兌換](../tabs/rewards_zh_TW.md)」分頁把一個項目的用途設為「**🎭 情境點歌**」（或用「**＋ 新增兌換項目**」建立一個）。
   到 Twitch 為它開啟「**要求觀眾輸入文字**」，不然 Claude 不知道觀眾的心情。
2. 在清單下方輸入你的 **Anthropic API 金鑰**（在 console.anthropic.com 建立）。使用你自己的 Anthropic 帳號並由它計費。
   金鑰存在 `.env`，之後不會再顯示出來。
3. 「**🏷 幫歌曲標記心情**」（建議）：Claude 會讀雷虎練唱台裡每首歌的歌詞（沒有歌詞就只看歌名），記下它的心情，選歌會更準。
   整批送出半價，幾百首歌大約 1–3 美元，通常一小時內完成。做一次就好，新增歌曲後再按一次。沒有標記也可以選歌。

## 直播中

1. 兌換會出現在「[🎵 點歌佇列](../tabs/queue_zh_TW.md) → **待審核**」，先顯示「**⏳ Claude 正在選歌…**」，然後是歌名、原因（只有你看得到）、
   它的心情標記，和兩句要發到聊天室的話。
2. 看過那兩句；想改就改。
3. 然後：
   - 「**✓ 加入佇列，發中文**」或「**✓ 加入佇列，發英文**」：加入歌單，並把那一句發到聊天室；
   - 「**🔁 換一首**」：請 Claude 換一首歌（每換一次就是一次選歌的花費）；
   - 「**✕**」：拒絕，退還觀眾的點數。

加入歌單後就和一般點歌一樣：唱完標成完成，移除就退還。`!endingtk` 會把這位觀眾列在點歌。

**從哪些歌裡挑**：只會選 🎤 點歌可以點的歌，不會選已在歌單、正在演唱、這場唱過、在待審核等著，或這次已經提議過的歌。
不使用隨機點歌的冷卻天數：把兌換項目的點數設高一點，讓它成為特別的兌換。

**玩笑和奇怪的訊息**：Claude 只把觀眾的話當成心情，就算不是心情也會選一首歌。要不要拒絕（✕）由你決定。

## 花費

每次選歌約 0.01–0.05 美元。隔一段時間後的第一次比較貴（幾百首歌約 0.2 美元），因為歌單會完整送出一次，之後一小時內從 Anthropic 的快取讀取。
分頁上會顯示累計：「**目前花費：約 … 美元**」。選歌失敗也一樣會計費。

## 選歌紀錄

每次選歌都會寫進點歌系統資料夾的 `mood-picks.jsonl`，一行一筆：觀眾寫的話、選了哪首、Claude 的原因、兩句話和花費；接著是你發了中文、
英文還是改過的那句，或退還了。同一次兌換的每一行有相同的 `id`。直播後可以用來回顧：哪些心情選得怪、按了幾次 🔁、整晚花了多少。
裡面有觀眾寫的話：不要公開分享。

## 隱私

每次選歌會送給 Anthropic 的是觀眾寫的話（不含觀眾名稱）和你的歌單（歌名、歌手、心情標記）；標記心情時會送一次歌詞。點歌系統的其他資料都不會送出。

## 遇到問題

- 「**請先輸入 Anthropic API 金鑰**」或「**Anthropic 不接受這個 API 金鑰**」：輸入或換一個金鑰（🎟️ 兌換 → 🎭 情境點歌）。
- 「**Anthropic 現在請求太多**」：等一分鐘，再按 🔁。
- 「**Claude 不回答這個請求**」：拒絕（✕），或按 🔁。
- 「**已經沒有可以選的歌了**」：這場每首歌都已在歌單、唱過或提議過；拒絕它。
- 「**Claude 選歌時程式重新啟動了**」：按它的 🔁。
