# 📖 點歌系統使用說明

[English](README.md) · **繁體中文**

**第一次使用？** 先看[新手入門](STARTER_GUIDE_zh_TW.md)：安裝、安裝精靈和第一次直播。
安裝、設定檔和問題排解：[SETUP_zh_TW.md](../SETUP_zh_TW.md)。

在控制台裡，分頁列右邊的「**❓**」會打開你目前所在分頁的說明。

## 控制台的分頁

| 分頁 | 用途 |
|---|---|
| [🎵 點歌佇列](tabs/queue_zh_TW.md) | 點歌：正在演唱、待唱、待審核、已唱；隨機點歌；練習分頁 |
| [🎤 雷虎練唱台](tabs/leihu_zh_TW.md) | 伴奏和歌詞；找 YouTube 連結；📱 平板上的提詞機 |
| [💬 聊天室](tabs/chat_zh_TW.md) | 即時聊天室、要宣讀、發言、管理、Shoutout、揪團、置頂 |
| [🎛 模式](tabs/modes_zh_TW.md) | 按一下就把 Streamlabs／OBS 和點歌系統切成唱歌、聊天或休息 |
| [👕 換裝](tabs/outfits_zh_TW.md) | 用兌換換 veadotube mini 的服裝 |
| [🔔 通知](tabs/alerts_zh_TW.md) | 追隨／訂閱／小奇點／揪團通知，以及 🎟️ 兌換特效 |
| [🎟️ 兌換](tabs/rewards_zh_TW.md) | 每個頻道點數兌換項目的用途；新增項目；交給點歌系統管理 |
| [🤖 機器人](tabs/bot_zh_TW.md) | 自己的聊天室指令和定時訊息，取代 Nightbot |

## 跨分頁的功能

| 說明 | 內容 |
|---|---|
| [🎭 情境點歌](features/mood-requests_zh_TW.md) | Claude 依觀眾的心情選歌；花費；選歌紀錄 |
| [🎬 Clip、感謝名單和揪團](features/clips-and-rolls_zh_TW.md) | `!so`、`!watch`、`!tk`、`!endingtk`、統一 Clip 音量、搭配片尾名單揪團 |
| [🖼 疊加層和 🎨 外觀](features/overlays_zh_TW.md) | OBS 的每個瀏覽器來源；主題、文字大小、疊加層語言 |
